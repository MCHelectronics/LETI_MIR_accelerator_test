# QPSK SDR Lab: подключение и проверка 2RX/2TX

## USB и Ethernet — разные пути

USB-разъём **DATA** предназначен для данных. Один кабель в **5V-IN** может
питать плату, но не создаёт соединения с ПК. Сверяйте маркировку своего экземпляра.
После подключения выполните `lsusb` и посмотрите появившийся сетевой интерфейс
через `ip -br address`. Не включайте передачу на этом этапе.

Есть два варианта доступа через тот же USB-кабель:

- `ip:192.168.2.1` — libiio по USB-сетевому интерфейсу, если такой адрес задан;
- `usb:...` — прямой USB-backend libiio. Актуальный URI показывает
  `build/iio-install/bin/iio_info -s` с локальным `LD_LIBRARY_PATH`.

Номера USB-шины и устройства меняются при переподключении: не копируйте URI
из чужого примера. Для RJ45 тоже используется `ip:АДРЕС`, но адрес относится
к Ethernet платы, а не к USB-сетевому интерфейсу. ПК и плата должны иметь
разные адреса в одной подсети; не назначайте одну подсеть двум интерфейсам ПК
без понимания маршрутизации.

## config.txt

В поддерживающих этот механизм прошивках плата появляется как USB-накопитель.
Перед правкой сохраните копию его `config.txt`. Меняйте только нужные поля
**в существующих секциях**, не заменяйте весь файл следующим фрагментом:

```ini
[NETWORK]
hostname = pluto
ipaddr = 192.168.2.1
ipaddr_host = 192.168.2.10
netmask = 255.255.255.0

[USB_ETHERNET]
ipaddr_eth = 192.168.70.150
netmask_eth = 255.255.255.0
```

Первая секция — USB-сеть; вторая — Ethernet в прошивке QPSK SDR Lab.
Это пример, не обязательные адреса. В частности, Ethernet-адрес ПК можно
задать как `192.168.70.10/24`, если эта подсеть свободна. `ipaddr_host` не
настраивает автоматически произвольный Ethernet-интерфейс компьютера.

Сохраните файл и выполните **извлечение накопителя** средствами ОС, сохраняя
питание платы. Простое закрытие редактора или отключение кабеля не равнозначно
команде извлечения. Дождитесь применения настроек; порядок перезапуска сверяйте
с документацией своей прошивки. После этого проверьте новый адрес, `config.txt`
и `iio_info -u ip:АДРЕС`. Не меняйте `dfu`, `reset`, `calibrate` для настройки IP.
Перепрошивка и команды `fw_setenv` не входят в эту процедуру.

## Права для прямого USB

Для IP-backend udev-доступ к USB-узлу libiio не требуется. Для `usb:` сначала
проверьте, работают ли уже правила вашей системы. Если обычному пользователю
отказано в доступе, выпишите USB-ID из `lsusb`. Для активного локального сеанса
рабочего стола с systemd-logind можно подготовить точечное правило. Создайте
в редакторе файл `build/70-qpsk-sdr-lab.rules`, заменив `VVVV` и `PPPP` четырьмя
шестнадцатеричными цифрами производителя и продукта **своей** платы:

```udev
SUBSYSTEM=="usb", ENV{DEVTYPE}=="usb_device", ATTR{idVendor}=="VVVV", ATTR{idProduct}=="PPPP", TAG+="uaccess"
```

Не копируйте шаблон с незаменёнными полями. Проверьте файл и установите его:

```bash
sudo install -m 0644 build/70-qpsk-sdr-lab.rules /etc/udev/rules.d/70-qpsk-sdr-lab.rules
sudo udevadm control --reload-rules
```

Перед копированием убедитесь, что файла `70-qpsk-sdr-lab.rules` ещё нет; имеющийся
файл сначала сравните и сохраните. Затем переподключите плату и повторите
`iio_info -s` обычным пользователем. Не назначайте всем USB-устройствам права 777.
Это правило рассчитано на локальный активный сеанс, не на SSH или системную
службу: для них администратор назначает отдельную группу и права по политике
лаборатории. Число `70` ставит правило до обработки `uaccess` системным
`73-seat-late.rules`. Правило не заменяет проверку подходящего интерфейса/URI.

## Проверка обоих радиоканалов

```bash
LD_LIBRARY_PATH="$PWD/build/iio-install/lib" \
  ./build/iio-install/bin/iio_info -u ip:192.168.2.1
LD_LIBRARY_PATH="$PWD/build/iio-install/lib" \
  ./build/ch02-iio/qpsk_channels ip:192.168.2.1
```

Ожидаем `ad9361-phy`, RX-устройство `cf-ad9361-lpc` и TX-устройство
`cf-ad9361-dds-core-lpc`. В каждом потоковом устройстве нужны scan-элементы
`voltage0`–`voltage3`: I1,Q1,I2,Q2. В управляющем `ad9361-phy` нумерация другая:
не считайте его каналы компонентами потокового буфера.

Если пар только по одной, одного изменения приложения недостаточно. Сохраните
описание IIO и версию прошивки; проверьте с преподавателем, какой 2RX2TX-образ
предназначен именно для вашей платы. Не применяйте случайную инструкцию для
ADALM-Pluto, LibreSDR или другой ревизии только из-за похожего AD936x.

Положительный результат подтверждает разметку, но не фазовую калибровку,
синхронность, пропускную способность или работоспособность RF-портов. Например,
два RX и два TX при 1 Мвыб/с и 16-битном хранении каждой I/Q-компоненты дают
суммарно 16 Мбайт/с полезных IQ-данных без накладных расходов транспорта.

Источники: [описание config.txt (Analog Devices)](https://wiki.analog.com/university/tools/pluto/users/customizing),
[официальный пример libiio](https://github.com/analogdevicesinc/libiio/blob/v0.26/examples/ad9361-iiostream.c).
Особенности Ethernet сверены с руководством изготовителя платы;
механизм конкретной установленной прошивки ещё проверяется на стенде.
